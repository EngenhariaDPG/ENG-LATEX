# Baseline documental do repositório

- Estado: proposta para revisão
- Data: 2026-11-23
- Issue/PR: a definir

## Contexto

O repositório precisa apresentar com clareza a direção FORGE, preservar o material EngLaTeX já publicado e oferecer um fluxo rastreável para contribuições revisáveis.

## Decisão proposta

Manter o ZIP EngLaTeX 1.1 na raiz e sem alterações nesta etapa. Organizar a documentação em `docs/`, manter instruções de contribuição em `CONTRIBUTING.md` e usar modelos de GitHub Issues e pull requests para delimitar entregas e revisões. Mudanças na branch principal devem passar pelas revisões e aprovações do projeto.

## Alternativas consideradas

- Extrair ou reestruturar o código-fonte agora: não adotado nesta etapa.
- Mover o ZIP para outra pasta: não adotado para preservar o caminho já compartilhado.
- Escolher uma licença ou iniciar uma migração: fora do escopo desta reorganização.

## Consequências

A página inicial e o planejamento ficam mais fáceis de navegar, e tarefas paralelas podem declarar arquivos reservados e dependências. O código não é modificado. A direção de longo prazo, licença e migração permanecem pendentes de decisão do responsável pelo projeto.
